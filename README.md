AI SMM Assistant — bu Instagram blogerlar, kontent yaratuvchilar, kichik bizneslar, SMM mutaxassislari va agentliklarga AI orqali Instagram akkauntini tahlil qilish, virusli Reels ssenariylari yaratish va auditoriyani o‘stirishda yordam beruvchi zamonaviy, to‘liq ishlaydigan SaaS platformasi.

## 🛠 Texnologiyalar

- **Frontend**: Next.js 14 (App Router), React 18, TypeScript, Tailwind CSS, Recharts, Lucide Icons.
- **Backend**: Next.js API Routes (REST API), JWT autentifikatsiya, HTTP-only xavfsiz cookie.
- **Database**: Prisma ORM, SQLite (`file:./dev.db`) out-of-the-box darhol ishlash uchun, PostgreSQL'ga oson o‘tkazish imkoniyati bilan.
- **AI Engine**: Google Gemini API integratsiyasi + Algoritmik SMM generator.
- **Dizayn standarti**: `taste-skill` v2 (anti-slop art direction).
